# 拖跑 (tuopao)

Android 端虚拟定位 / 轨迹模拟工具。在地图上拖出椭圆跑道，设置中心坐标、半轴、方位角、速度与圈数，即可通过 Android「模拟位置」向系统持续注入 GPS 轨迹，用于轨迹算法调试与虚拟定位测试。

## 功能特性

- **地图可视化**（高德瓦片底图，无需 Key）：拖动移动椭圆、拖 A/B 手柄调整角度与大小
- **跑道参数**：BD-09 中心 / 半轴或周长 / 方位角 / 速度 / 圈数 / 真实度（轨迹抖动强度）
- **地点搜索**：在线 Photon / OSM（可选填高德 Key 提升中文 POI 精度）+ 本地收藏
- **播放控制**：预览 / 开始 / 停止 / 重新开始 / 实时倍速（0.5x ~ 4x）
- **悬浮窗**：在其他 App 上层显示小地图
- **预设与锁定**：保存常用跑道参数，防止误触
- **坐标系自动换算**：界面 BD-09 ↔ 注入 WGS-84、底图 GCJ-02

## 使用说明

1. 手机「开发者选项」中开启 **「选择模拟位置应用」**，选中「拖跑」。
2. 打开本应用，搜索或拖动地图定位到目标操场，调整跑道形状与速度。
3. 点 **「开始回放」**，下拉通知栏出现「拖跑 · 轨迹回放中」即开始注入位置（约 1 秒/点）。
4. 切换到需要定位的 App，即可看到位置沿椭圆移动。
5. 可选：开启悬浮窗，在其他 App 上层查看小地图。

## 构建

`build_apk.py` 是一个**零依赖 APK 打包器**：自实现 AXML / ARSC 二进制、javac 编译、d8 转 dex、apksigner v2 签名。构建环境需准备：

- JDK 8（脚本默认 `~/android-build/jdk`）
- Android `android.jar`（脚本默认 `~/android-build/pkg/android.jar`）
- build-tools 的 `d8.jar` 与 `apksigner.jar`（脚本默认 `~/android-build/pkg/bt/lib/`）

```bash
python3 build_apk.py   # 生成 拖跑.apk / tuopao.apk
```

> 不想自己构建的话，可直接下载已打包好的 **`tuopao.apk`**（见下方 Release）。
